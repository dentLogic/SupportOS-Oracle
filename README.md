# SupportOS Oracle

A Linux-only, local-first support desk companion for your Help Scout mailbox (Rust + Tauri 2 + Leptos, no JavaScript).
Linux only: install the `.deb` from the [nightly release](https://github.com/dentLogic/SupportOS-Oracle/releases/tag/nightly) (unsigned development build).
Early development — see [PROGRESS.md](PROGRESS.md) for what works today.
